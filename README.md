# Полевой планировщик безопасности

Итоговый проект по дисциплине "Безопасность жизнедеятельности".

## Что умеет приложение
- **Создание плана:** позволяет указать локацию, дату, тип работ и условия (лес, город, промзона). План сохраняется в браузере (localStorage) и имеет стабильный ID.
- **Мониторинг:** запрашивает актуальную погоду через API Open-Meteo по локации из плана.
- **Подготовка:** формирует чек-лист, который зависит от выбранных условий.
- **Источники:** содержит памятку по задымлению, ссылки на официальные ресурсы и ограничения.
- **Печать:** генерирует отчет с входными условиями, временем сбора данных, результатами чек-листа, источниками и ограничениями.

## Источники данных
- **Open-Meteo API** — для получения текущих погодных условий (проверено: [ДД.ММ.ГГГГ]).
- **МЧС России** (mchs.gov.ru) — рекомендации по безопасности.
- **Роспотребнадзор** (rospotrebnadzor.ru) — санитарные нормы.
- **Памятка по задымлению** — авторская разработка (Задание 1).

## Ограничения
1. Данные о погоде актуальны только на момент запроса.
2. Приложение не заменяет официальные инструкции и не выдает разрешение на работы.
3. Чек-лист носит рекомендательный характер.

## Как проверить работоспособность
1. Заполнить форму на вкладке «План» и нажать «Сохранить».
2. Обновить страницу (F5) — данные плана должны восстановиться.
3. Сменить условия (например, с «Лес» на «Город») — чек-лист на вкладке «Подготовка» должен измениться.
4. Нажать «Печать отчёта» — должен открыться документ со всеми данными.
